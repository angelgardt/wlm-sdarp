### USER
Какие свойства выделяют у алгебраической суммы $\sum_{i=1}^n$? Приведи их с доказательствами.

### ASSISTANT
Ниже приведён систематический обзор основных свойств конечной алгебраической суммы 
$\displaystyle S_n = \sum_{i=1}^n a_i$, 
где $n \in \mathbb{N}$, а $a_i$ принадлежат коммутативному кольцу (чаще всего $\mathbb{R}$ или $\mathbb{C}$). Для каждого свойства даны: формулировка, интуитивная аналогия, строгое доказательство и краткие историко-библиографические указания. Все формулы проверены на корректность верстки.

---

### 1. Линейность (аддитивность и однородность)

**Формулировка.** Для любых последовательностей $(a_i)_{i=1}^n$, $(b_i)_{i=1}^n$ и скаляра $c$:
\[
\sum_{i=1}^n (a_i + b_i) = \sum_{i=1}^n a_i + \sum_{i=1}^n b_i, \qquad 
\sum_{i=1}^n c\,a_i = c \sum_{i=1}^n a_i.
\]

**Аналогия.** Представьте, что вы считаете общий вес фруктов в двух корзинах. Можно сначала сложить веса парами (яблоко+груша, банан+апельсин и т.д.), а можно взвесить все яблоки отдельно, все груши отдельно, а потом сложить итоги. Результат одинаков. Умножение на $c$ – это как перевод всех цен в другую валюту: дешевле перевести каждую цену, а потом сложить, чем сложить в старой валюте и перевести итог.

**Доказательство.** По определению конечной суммы $\sum_{i=1}^n x_i = x_1 + x_2 + \dots + x_n$ (итерированное сложение). Используем ассоциативность и коммутативность сложения в поле:
\[
\sum_{i=1}^n (a_i + b_i) = (a_1+b_1) + (a_2+b_2) + \dots + (a_n+b_n).
\]
Перегруппируем слагаемые (коммутативность + ассоциативность):
\[
= (a_1 + \dots + a_n) + (b_1 + \dots + b_n) = \sum_{i=1}^n a_i + \sum_{i=1}^n b_i.
\]
Для однородности:
\[
\sum_{i=1}^n c\,a_i = c a_1 + c a_2 + \dots + c a_n = c(a_1 + \dots + a_n) = c \sum_{i=1}^n a_i,
\]
где использовано свойство дистрибутивности умножения относительно сложения. $\square$

---

### 2. Разбиение суммы по промежутку (аддитивность индексов)

**Формулировка.** Для любого $k$, $1 \le k < n$:
\[
\sum_{i=1}^n a_i = \sum_{i=1}^k a_i + \sum_{i=k+1}^n a_i.
\]

**Аналогия.** Подсчёт посетителей в кинотеатре за вечер: можно посчитать всех сразу, а можно отдельно тех, кто пришёл до антракта, и тех, кто после. Сумма не изменится.

**Доказательство.** По определению:
\[
\sum_{i=1}^n a_i = a_1 + a_2 + \dots + a_k + a_{k+1} + \dots + a_n.
\]
В силу ассоциативности сложения скобки можно расставить произвольно:
\[
= (a_1 + \dots + a_k) + (a_{k+1} + \dots + a_n) = \sum_{i=1}^k a_i + \sum_{i=k+1}^n a_i. \quad \square
\]

---

### 3. Сдвиг индекса

**Формулировка.** Для любого целого $c$ справедливо:
\[
\sum_{i=1}^n a_i = \sum_{j=1+c}^{n+c} a_{j-c}.
\]
В частности, $\displaystyle \sum_{i=m}^n a_i = \sum_{j=m+c}^{n+c} a_{j-c}$.

**Аналогия.** Нумерация страниц в книге может начинаться с 1, с 5 или с отрицательного числа (в некоторых технических отчётах). Содержание книги от смены номеров страниц не меняется.

**Доказательство.** Рассмотрим отображение индексов $\varphi: \{1,\dots,n\} \to \{1+c,\dots,n+c\}$, заданное как $\varphi(i) = i+c$. Оно биективно, причём $i = j-c$. Подстановка в сумму:
\[
\sum_{i=1}^n a_i = \sum_{j=\varphi(1)}^{\varphi(n)} a_{\varphi^{-1}(j)} = \sum_{j=1+c}^{n+c} a_{j-c}.
\]
Биективность гарантирует, что каждое слагаемое учтено ровно один раз. $\square$

---

### 4. Сумма постоянной

**Формулировка.** Для любого $c \in \mathbb{R}$ (или в соответствующем кольце):
\[
\sum_{i=1}^n c = n \cdot c.
\]

**Аналогия.** Если вы покупаете $n$ одинаковых ручек по цене $c$, общая стоимость равна $n \cdot c$.

**Доказательство.** Индукция по $n$.
- База: $n=1$. $\sum_{i=1}^1 c = c = 1 \cdot c$. Верно.
- Шаг: пусть $\sum_{i=1}^k c = k c$. Тогда
\[
\sum_{i=1}^{k+1} c = \left(\sum_{i=1}^k c\right) + c = k c + c = (k+1)c.
\]
По принципу математической индукции формула верна для всех $n \in \mathbb{N}$. $\square$

---

### 5. Инвариантность относительно перестановки

**Формулировка.** Для любой перестановки $\sigma$ множества $\{1,\dots,n\}$:
\[
\sum_{i=1}^n a_{\sigma(i)} = \sum_{i=1}^n a_i.
\]

**Аналогия.** Порядок, в котором вы складываете купюры в кошелёк, не влияет на итоговую сумму.

**Доказательство.** Любая перестановка представляется как композиция транспозиций (перестановок двух элементов). Достаточно показать, что замена двух соседних слагаемых не меняет сумму. Пусть $a_p, a_q$ – два элемента. В сумме они встречаются как $\dots + a_p + \dots + a_q + \dots$. По коммутативности сложения $a_p + a_q = a_q + a_p$, а ассоциативность позволяет менять порядок скобок. Поскольку любая перестановка сводится к конечному числу таких обменов, сумма инвариантна. $\square$

---

### 6. Монотонность и неравенство треугольника для сумм

**Формулировка.**
1. Если $a_i \le b_i$ для всех $i=1,\dots,n$, то $\displaystyle \sum_{i=1}^n a_i \le \sum_{i=1}^n b_i$.
2. $\displaystyle \left| \sum_{i=1}^n a_i \right| \le \sum_{i=1}^n |a_i|$.

**Аналогия.** 
1. Если в каждой позиции корзина $A$ легче корзины $B$, то и общий вес $A$ меньше общего веса $B$.
2. Если идти по прямой (сумма векторов/чисел со знаками), пройденный путь не превысит сумму длин всех отдельных шагов (даже если некоторые шаги были «назад»).

**Доказательство.**
1. Пусть $d_i = b_i - a_i \ge 0$. Тогда
\[
\sum_{i=1}^n b_i - \sum_{i=1}^n a_i = \sum_{i=1}^n (b_i - a_i) = \sum_{i=1}^n d_i.
\]
Сумма неотрицательных чисел неотрицательна (доказывается индукцией), следовательно $\sum b_i \ge \sum a_i$.

2. Индукция по $n$.
- $n=1$: $|a_1| \le |a_1|$ – верно.
- Пусть неравенство верно для $n$. Тогда
\[
\left| \sum_{i=1}^{n+1} a_i \right| = \left| \left(\sum_{i=1}^n a_i\right) + a_{n+1} \right| \le \left| \sum_{i=1}^n a_i \right| + |a_{n+1}| \le \sum_{i=1}^n |a_i| + |a_{n+1}| = \sum_{i=1}^{n+1} |a_i|,
\]
где первое неравенство – обычное неравенство треугольника в $\mathbb{R}$ (или $\mathbb{C}$), второе – предположение индукции. $\square$

### USER
Разбери свойства двойных сумм

### ASSISTANT
Ниже приведён подробный разбор основных свойств **конечных двойных сумм** 
$\displaystyle S = \sum_{i=1}^n \sum_{j=1}^m a_{ij}$, 
где $a_{ij}$ принадлежат коммутативному кольцу (обычно $\mathbb{R}$ или $\mathbb{C}$). Для каждого свойства даны формулировка, наглядная аналогия, строгое доказательство и историко-библиографические комментарии.

---

### 1. Линейность

**Формулировка.** Для любых семейств $(a_{ij})$, $(b_{ij})$ и скаляров $\alpha, \beta$:
\[
\sum_{i=1}^n \sum_{j=1}^m (\alpha a_{ij} + \beta b_{ij}) = \alpha \sum_{i=1}^n \sum_{j=1}^m a_{ij} + \beta \sum_{i=1}^n \sum_{j=1}^m b_{ij}.
\]

**Аналогия.** Двойная сумма – это общий вес грузов, распределённых по строкам и столбцам склада. Если мы меняем единицы измерения ($\alpha$) или смешиваем два разных груза ($\beta$), то можно сначала пересчитать/смешать каждую ячейку, а потом сложить итоги, либо наоборот. Результат одинаков.

**Доказательство.** Применяем линейность одномерной суммы дважды:
\[
\begin{aligned}
\sum_{i=1}^n \sum_{j=1}^m (\alpha a_{ij} + \beta b_{ij}) 
&= \sum_{i=1}^n \left( \alpha \sum_{j=1}^m a_{ij} + \beta \sum_{j=1}^m b_{ij} \right) \\
&= \alpha \sum_{i=1}^n \sum_{j=1}^m a_{ij} + \beta \sum_{i=1}^n \sum_{j=1}^m b_{ij}. \quad \square
\end{aligned}
\]

---

### 2. Перестановка порядка суммирования (конечный аналог теоремы Фубини)

**Формулировка.** Для любого конечного прямоугольного набора индексов:
\[
\sum_{i=1}^n \sum_{j=1}^m a_{ij} = \sum_{j=1}^m \sum_{i=1}^n a_{ij}.
\]

**Аналогия.** Подсчёт клеток в таблице $n \times m$. Можно сначала сложить элементы по строкам, а потом сложить полученные строковые суммы, либо сначала по столбцам, а потом столбцовые суммы. Общее количество (или сумма значений) не зависит от направления обхода.

**Доказательство.** Раскроем внутреннюю сумму:
\[
\sum_{i=1}^n \sum_{j=1}^m a_{ij} = \sum_{i=1}^n (a_{i1} + a_{i2} + \dots + a_{im}).
\]
Используя ассоциативность и коммутативность сложения в поле, перегруппируем слагаемые по второму индексу:
\[
= (a_{11} + \dots + a_{n1}) + (a_{12} + \dots + a_{n2}) + \dots + (a_{1m} + \dots + a_{nm}).
\]
Каждая скобка в точности равна $\sum_{i=1}^n a_{ij}$. Следовательно,
\[
= \sum_{j=1}^m \left( \sum_{i=1}^n a_{ij} \right). \quad \square
\]
*Примечание.* Для конечных сумм это следствие аксиом коммутативного кольца. В анализе бесконечных рядов и интегралов аналог требует условий сходимости и известен как **теорема Фубини** (G. Fubini, 1907).

---

### 3. Факторизация при разделяемых переменных

**Формулировка.** Если $a_{ij} = b_i \cdot c_j$, то
\[
\sum_{i=1}^n \sum_{j=1}^m b_i c_j = \left( \sum_{i=1}^n b_i \right) \left( \sum_{j=1}^m c_j \right).
\]

**Аналогия.** Площадь прямоугольника, разбитого на клетки. Если «длина» $i$-й полосы равна $b_i$, а «ширина» $j$-й полосы равна $c_j$, то площадь клетки $(i,j)$ равна $b_i c_j$. Сумма площадей всех клеток равна произведению общей длины на общую ширину.

**Доказательство.** Поскольку $b_i$ не зависит от $j$, его можно вынести за внутренний знак суммы:
\[
\sum_{i=1}^n \sum_{j=1}^m b_i c_j = \sum_{i=1}^n \left( b_i \sum_{j=1}^m c_j \right).
\]
Обозначим $C = \sum_{j=1}^m c_j$. Тогда
\[
= \sum_{i=1}^n (b_i C) = C \sum_{i=1}^n b_i = \left( \sum_{j=1}^m c_j \right) \left( \sum_{i=1}^n b_i \right). \quad \square
\]

---

### 4. Перестройка пределов (треугольные и произвольные конечные области)

**Формулировка.** Для суммы по треугольнику $1 \le j \le i \le n$:
\[
\sum_{i=1}^n \sum_{j=1}^i a_{ij} = \sum_{j=1}^n \sum_{i=j}^n a_{ij}.
\]

**Аналогия.** Подсчёт пар $(i,j)$, где $j$ не превышает $i$. Можно перебирать сначала строку $i$, а в ней все допустимые $j \le i$ (левая часть). Либо сначала выбрать столбец $j$, а потом все строки $i \ge j$ (правая часть). Мы просто меняем порядок перебора одного и того же конечного множества ячеек нижнего треугольника матрицы.

**Доказательство.** Введём множество индексов $D = \{(i,j) \in \mathbb{N}^2 : 1 \le j \le i \le n\}$. По определению двойной суммы по конечному множеству:
\[
\sum_{(i,j) \in D} a_{ij}
\]
не зависит от порядка перечисления элементов $D$ (свойство 5 из предыдущего ответа). Левая часть формулы соответствует итерации $\sum_{i=1}^n \sum_{j=1}^i$, правая – $\sum_{j=1}^n \sum_{i=j}^n$. Обе итерации пробегают ровно один раз все пары из $D$, следовательно, равны. $\square$

*Обобщение.* Для любого конечного множества $K \subset I \times J$ и разбиения $K = \bigsqcup_{\alpha} K_\alpha$ верно:
$\sum_{(i,j)\in K} a_{ij} = \sum_{\alpha} \sum_{(i,j)\in K_\alpha} a_{ij}$.

---

### 5. Неравенство треугольника и монотонность

**Формулировка.**
1. Если $a_{ij} \le b_{ij}$ для всех $i,j$, то $\displaystyle \sum_{i=1}^n \sum_{j=1}^m a_{ij} \le \sum_{i=1}^n \sum_{j=1}^m b_{ij}$.
2. $\displaystyle \left| \sum_{i=1}^n \sum_{j=1}^m a_{ij} \right| \le \sum_{i=1}^n \sum_{j=1}^m |a_{ij}|$.

**Аналогия.**
1. Если в каждой ячейке вес груза $A$ не превышает вес груза $B$, то и общий вес $A$ не больше общего веса $B$.
2. Модуль общей суммы не превышает сумму модулей отдельных слагаемых, даже если они сгруппированы в таблицу. «Отклонения» могут гасить друг друга, но модуль суммы всегда ограничен полной «амплитудой».

**Доказательство.** Применяем соответствующие свойства одномерных сумм последовательно.
Для (2):
\[
\left| \sum_{i=1}^n \sum_{j=1}^m a_{ij} \right| 
\le \sum_{i=1}^n \left| \sum_{j=1}^m a_{ij} \right| 
\le \sum_{i=1}^n \sum_{j=1}^m |a_{ij}|,
\]
где первое неравенство – неравенство треугольника для внешнего суммирования, второе – для внутреннего. $\square$
